# Registro fonti

Ogni file della knowledge base cita le sue fonti con un codice tra parentesi quadre. Il prefisso dice il tipo di fonte:

| Prefisso | Tipo |
|---|---|
| `S` | Pagina del sito del cliente |
| `D` | Documento della cartella Drive di progetto |
| `M` | Riunione (transcript) |
| `C` | Contenuto esistente di {{CLIENTE}} fornito come esempio |
| `E` | Fonte esterna (normative, studi, dati di settore) |
| `G` | Estrazione di Google Search Console (`raw/gsc/`) |
| `X` | Estrazione di Semrush (`raw/semrush/`) |
| `H` | Download di HubSpot AEO (`raw/hubspot-aeo/`) |
