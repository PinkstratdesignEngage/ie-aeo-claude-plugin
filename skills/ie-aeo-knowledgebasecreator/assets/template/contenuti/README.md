# Contenuti

I contenuti prodotti con le skill del plugin IE-AEO: content brief, bozze e versioni approvate. Ogni file ha nel frontmatter lo stato (`brief`, `bozza`, `approvato`, `pubblicato`), le domande AEO che copre e le fonti usate.

| Cartella | Contenuto |
|---|---|
| `blog/` | Articoli del blog |
| `faq-prodotto/` | FAQ e Schema.org delle pagine prodotto |
| `case-study/` | Case study in formato AEO e registro dei casi del cliente, con dati e permessi |
| `glossario/` | Pagine del glossario pubblico |
| `modelli/` | Modelli di struttura approvati, uno per tipologia di contenuto |
| `piano-editoriale/` | Il piano dei contenuti di ogni mese, con la configurazione del cliente |
| `traduzioni/` | Lingue, varianti e mercati delle traduzioni; i file tradotti stanno accanto all'originale |
| `pubblicazione/` | Dove va ogni tipo di contenuto in HubSpot (blog, pagine, lingue) |

Le categorie del blog sono in [categorie-blog.md](categorie-blog.md). Le traduzioni stanno accanto all'originale, con il suffisso della lingua (`-en`).

I contenuti ristrutturati da una versione già pubblicata seguono il modello della loro tipologia, se esiste. Il primo piano approvato di una tipologia diventa il suo modello.
